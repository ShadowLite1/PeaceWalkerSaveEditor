# Peace Walker Custom Quotes ASI

This optional plugin lets Peace Walker load custom Details Quotes without the Soldier Editor remaining open.

It requires an ASI loader. MGSPatriotFix already includes a compatible Ultimate ASI Loader installation.

Install `PeaceWalkerCustomQuotes.asi` in the game's `mgspw\scripts` folder. The plugin finds the newest Peace Walker PC save that has a matching `.pwquotes.json` companion file and loads its quotes automatically.

The plugin is build-specific. If a game update changes the quote resolver, remove the ASI until an updated build is available. Removing the plugin never modifies or damages the save.
